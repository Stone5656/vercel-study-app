# SQL 演習ファイル

## 目的

- `000_check_connection.sql`: 接続先データベース・ユーザー、SQL 実行可否、DB サーバー時刻を読み取り専用で確認します。
- `010_setup_sample_products.sql`: 演習用 `products` テーブルとサンプルデータを準備し、登録内容を表示します。

## 実行方法と対象

Neon Console の SQL Editor で、以下の順序で手動実行します。

1. `000_check_connection.sql`
2. `010_setup_sample_products.sql`（接続先を確認し、既存テーブルの内容が教材と一致すると確認できた後）

対象は授業で接続確認に使用した Neon ブランチおよび PostgreSQL データベースです。Preview と Production が同一 DB を参照する教材設定を前提にします。具体的なブランチ名・DB 名は SQL Editor で確認し、実行後にここへ記録します。

SQL ファイルを GitHub に保存しただけでは SQL は実行されず、Neon のデータベースにも変更は加わりません。
